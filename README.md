# ココロミー企業パートナー LP（静的モック）

長野の学生メディア「ココロミー」（運営: 株式会社OMOMO）の企業向け年間プログラムの紹介LPです。
要件は [lp-spec.md](lp-spec.md)（v0.4）、作業の経緯と引き継ぎは [WORKLOG.md](WORKLOG.md) を参照してください。

## 見かた

`index.html` をダブルクリックすると、ブラウザで開けます。サーバーは不要です。


## 要件と違う点（ユーザーの指示による）

lp-spec.md と、チャットでのユーザーの指示が食い違うときは、**ユーザーの指示を優先**する（2026-10-23 指示）。

- **ベース背景色**: §3 の `#FAF6EC` ではなく、ユーザーの指示で「名称未設定のデザイン.png」の地の色 `#FCF6E5` を使っている。
- **料金の年額**: §5-6 は「年間契約総額（480,000円）を小さく併記」だが、ユーザーの指示で「契約は年間、支払いは月払い（月額40,000円）か年払い（年額400,000円）を選べる」形にしている。月払いの12か月合計 480,000円は、月払いの下に小さく表示。
- **ヒーロー（FV）に料金を載せない**: §5-1 は「月額 40,000円（税込）・年間契約」をヒーローに表示する指定だが、ユーザーの指示で外し、価値の訴求（3項目）に置き換えた。料金は #6 で見せる。
- （v0.3 では要件と違っていた「ヒーローの人物写真」「ヒーロー背景のオレンジ」は、v0.4 の §3・§4 で認められたため、ここから外した）

## 議論ログ（設計判断の記録。lp-spec.md §7）

新しい判断は、下に日付付きで追記してください。

### CTA位置（2026-10-23）
- **決定**: 問い合わせCTAは #4（サービス内容）の後・#6（料金）の後・#8（お問い合わせ）に置く。ヒーローと #2（おすすめ）の直後には置かない。ヒーローの主ボタンは「サービス内容を見る」（ページ内スクロール）。固定ヘッダーには、控えめな「お問い合わせ」のテキストリンクを残す。
- **理由**: 想定は、ページのみによる新規開拓（初見の訪問者）。信頼・安全感の材料（実績、サービス内容、企業の負担）を見せてから判断を促すため。
- **留保**: 流入経路が未確定。営業先への個別送付が中心になる場合は、ヒーローにCTAを置く案を再検討する。効果は未計測。

### ヒーローは写真を主役にする（2026-10-23）
- **決定**: PCは、文字を左（全体の約4割）、写真を右に置き、写真を画面の右端まで広げる。写真は 3:2 の比率のまま見せ、左右の人物を切らない。スマホは、写真を画面幅いっぱいで先に見せ、文字をその下に置く。「※ 写真はイメージです」は写真の右下に重ねる。
- **理由**: ユーザーの指示（「ヒーローの写真を前面に押し出す」）。学生と社会人が同じテーブルで話す場面が、サービス（交流会・取材）をいちばん直接的に伝えるため。
- **検討した案**: 写真を縦長に切り抜いて画面の高さいっぱいに置く案は、左の学生が画面から切れたため採用しなかった。
- **留保**: 実写に差し替えるとき、写真の構図によっては切り抜き位置（CSS の `object-position`）の調整が必要。

### 料金は月払い／年払いの2つを並べる（2026-10-23）
- **決定**: 契約は年間。支払いは月払い（月額40,000円）と年払い（年額400,000円）を同じ大きさのカードで並べる。ヒーローは「月額 40,000円（税込）・年間契約」を主にし、「年払いなら 400,000円（税込）」を小さく添える。年払いのカードには「月払いの合計より 80,000円少なくなります」と、計算で出る差額だけを書く。
- **理由**: ユーザーの指示。年額の金額を主役にすると、ヒーローの「月額4万円」という入口の分かりやすさが下がるため、ヒーローは月額を主にした。
- **留保**: 年払いの金額が税込か、支払い時期（前払いか）は未確認。

### ヒーロー（FV）から料金を外す（2026-10-23）
- **決定**: ヒーローの「月額 40,000円（税込）・年間契約」「年払いなら 400,000円」を外し、企業が得られるものを3項目で示す（学生の目線で、自社の魅力を記事に／記事をWebとInstagramで発信／月1回の交流会で、学生と直接話せる）。料金は #6 料金でだけ見せる。
- **理由**: ユーザーの指示（「より価値の訴求に振る」）。最初に金額を見せると、価値を知る前に費用で判断されやすいため、まず価値を伝える。
- **留保**: ヘッダーのナビに「料金」があるので、金額を先に知りたい人はすぐ移動できる（スマホのヘッダーにはナビがない）。効果は未計測。

## 色を変えたいとき

`css/style.css` の冒頭 `:root { ... }` にある変数を変えると、ページ全体の色が変わります。

> メモ: 指定の緑 `#4E8A3A` に白文字の組み合わせはコントラスト比が約 4.2:1 で、基準の 4.5:1 に届きません。そのためボタンの地には濃い緑 `#3A6B2A`（約 6.3:1）を使っています。`#4E8A3A` はアイコン・装飾・枠線に使っています。
