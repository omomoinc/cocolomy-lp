# ココロミー企業パートナー LP（静的モック）

長野の学生メディア「ココロミー」（運営: 株式会社OMOMO）の企業向け年間プログラムの紹介LPです。
要件は [lp-spec.md](lp-spec.md)（v0.3）、作業の経緯と引き継ぎは [WORKLOG.md](WORKLOG.md) を参照してください。

## 見かた

`index.html` をダブルクリックすると、ブラウザで開けます。サーバーは不要です。

## ファイル構成

```
/
├─ index.html                     # LP本体（全8セクション）
├─ css/style.css                  # 色・角丸などは冒頭の :root（CSS変数）で管理
├─ js/main.js                     # ヘッダーの影／スクロール表示／フォーム（ダミー送信）
├─ assets/images/
│   ├─ hero-cafeteria.webp        # ヒーロー写真（PC用 1536×1024）
│   ├─ hero-cafeteria-sp.webp     # ヒーロー写真（スマホ用 768×512）
│   ├─ hero-bg-blur.webp          # ヒーロー背景（円のデザインをぼかしたもの）
│   ├─ placeholder/about.svg      # 仮画像（イラスト到着後に差し替え）
│   └─ articles/                  # 公開済み記事サムネイルの置き場（現在は空）
├─ README.md                      # このファイル（TODO一覧）
├─ WORKLOG.md                     # 作業記録・引き継ぎメモ
└─ lp-spec.md                     # 要件定義書
```

## 要件と違う点（ユーザーの指示による）

- **ヒーローに人物写真を使用**: lp-spec.md §4 は「人物写真は使わない」だが、ユーザーの指示で「Warm Cafeteria Conversation.png」を使っている。実在の学生・社員と誤解されないよう、alt と画面上に「※ 写真はイメージです」と表記。公開前に、写真の出どころ（AI生成か、撮影したものか）と、写っている人の許諾を確認すること。
- **ヒーロー背景にオレンジを含む**: §3 は「オレンジを使わない」だが、ユーザーの指示で「名称未設定のデザイン.png」（緑・黄・オレンジの円）をぼかして背景にしている。
- **ベース背景色**: §3 の `#FAF6EC` ではなく、ユーザーの指示で「名称未設定のデザイン.png」の地の色 `#FCF6E5` を使っている。

## 色を変えたいとき

`css/style.css` の冒頭 `:root { ... }` にある変数を変えると、ページ全体の色が変わります。

> メモ: 指定の緑 `#4E8A3A` に白文字の組み合わせはコントラスト比が約 4.2:1 で、基準の 4.5:1 に届きません。そのためボタンの地には濃い緑 `#3A6B2A`（約 6.3:1）を使っています。`#4E8A3A` はアイコン・装飾・枠線に使っています。

## 画像を作り直したいとき

ヒーローの WebP 3枚は、元画像（ダウンロードフォルダの `Warm Cafeteria Conversation.png` と `名称未設定のデザイン.png`）から、headless Edge の canvas 機能で変換したものです。手順は [WORKLOG.md](WORKLOG.md) の「画像の変換方法」を参照してください。
