# ココロミー企業パートナー LP（静的モック）

長野の学生メディア「ココロミー」（運営: 株式会社OMOMO）の企業向け年間プログラムの紹介LPです。
要件は [lp-spec.md](lp-spec.md)（v0.4）、作業の経緯と引き継ぎは [WORKLOG.md](WORKLOG.md) を参照してください。

## 見かた

`index.html` をダブルクリックすると、ブラウザで開けます。サーバーは不要です。

## ファイル構成

```
/
├─ index.html                     # LP本体（全8セクション）
├─ css/style.css                  # 色・角丸などは冒頭の :root（CSS変数）で管理
├─ js/main.js                     # ヘッダーの影／スクロール表示／フォーム（ダミー送信）
├─ assets/images/
│   ├─ hero-cafeteria.webp        # ヒーロー写真（PC用 1536×1024）
│   ├─ hero-cafeteria-sp.webp     # ヒーロー写真（スマホ用 768×512）
│   ├─ hero-bg-blur.webp          # ヒーロー背景（円のデザインをぼかしたもの）
│   ├─ placeholder/service.svg・case.svg  # 仮画像（差し替え予定）
│   └─ articles/                  # 公開済み記事のサムネイル（800×450 の WebP、4枚）
├─ README.md                      # このファイル（TODO一覧）
├─ WORKLOG.md                     # 作業記録・引き継ぎメモ
└─ lp-spec.md                     # 要件定義書
```

## 要件と違う点（ユーザーの指示による）

lp-spec.md と、チャットでのユーザーの指示が食い違うときは、**ユーザーの指示を優先**する（2026-10-23 指示）。

- **ベース背景色**: §3 の `#FAF6EC` ではなく、ユーザーの指示で「名称未設定のデザイン.png」の地の色 `#FCF6E5` を使っている。
- **料金の年額**: §5-6 は「年間契約総額（480,000円）を小さく併記」だが、ユーザーの指示で「契約は年間、支払いは月払い（月額40,000円）か年払い（年額400,000円）を選べる」形にしている。月払いの12か月合計 480,000円は、月払いの下に小さく表示。
- **ヒーロー（FV）に料金を載せない**: §5-1 は「月額 40,000円（税込）・年間契約」をヒーローに表示する指定だが、ユーザーの指示で外し、価値の訴求（3項目）に置き換えた。料金は #6 で見せる。
- **#2 課題提起の文言に「採用サイト」「採用広報」**: §6 は採用に関する語を禁止しているが、ユーザーが指定した文面のまま使っている（2026-10-23）。主訴求（認知）との関係は要検討。
- **#2 の形式**: §5 の「こんな企業におすすめ」（5項目）を、ユーザー指定の「こんなお悩みはありませんか？」（5項目）に置き換えた。
- **#3 の見出しと紹介文**: 「ココロミーの実績」→「ココロミーとは」。紹介文はユーザー指定の文面。株式会社OMOMOを「運営」ではなく「後援」と表記（§1 は「OMOMO = ココロミーを運営する企業」）。
- **ヒーローの説明文**: ユーザー指定の文面（「学生との一過性でない、持続的な交流の場を設計します。」ほか）。
- **#4 サービス内容に「年間活動レポート」を追加**（§5-4 の5項目 → 6項目）。料金の「含まれる内容」の表記も「年1回の年間活動レポート」に合わせた。
- **#5 ご利用の流れ**: 「取材→記事化→Instagram→交流」の4ステップを、年間スケジュールの図と「記事1本ができるまで」の4ステップに整理し直した。企業の負担（取材対応時間・確認回数）は各ステップの中に明記。
- （v0.3 では要件と違っていた「ヒーローの人物写真」「ヒーロー背景のオレンジ」は、v0.4 の §3・§4 で認められたため、ここから外した）

## 議論ログ（設計判断の記録。lp-spec.md §7）

新しい判断は、下に日付付きで追記してください。

### LP変更指示書（仮案）の試行（2026-10-27。ブランチ taihei's-laptop のみ）
- **内容**: [lp-changes.md](lp-changes.md) に沿って、主な打ち出しを「学生向け広報PR（オンライン＋オフライン）」に変え、構成を11セクションにした。「採用」への訴求はしない（学生を商品にしないため）。ココロミー（記事1本）は主役にせず、記事・ココロミーのInstagram・オモモ会を同列に並べる。
- **CTA**: 料金の後とフォームだけ（サービス詳細の後のCTAは削除）。
- **解釈したこと**: 指示書の「お悩み会」は「オモモ会」のことと解釈（要確認）。「新入生向けの紹介」は指示書の文言のまま。
- **留保**: 方向性は未確定（仮案）。採用しない場合は main（0dd5f90）の版に戻せる。

### CTA位置（2026-10-23）
- **決定**: 問い合わせCTAは #4（サービス内容）の後・#6（料金）の後・#8（お問い合わせ）に置く。ヒーローと #2（おすすめ）の直後には置かない。ヒーローの主ボタンは「サービス内容を見る」（ページ内スクロール）。固定ヘッダーには、控えめな「お問い合わせ」のテキストリンクを残す。
- **理由**: 想定は、ページのみによる新規開拓（初見の訪問者）。信頼・安全感の材料（実績、サービス内容、企業の負担）を見せてから判断を促すため。
- **留保**: 流入経路が未確定。営業先への個別送付が中心になる場合は、ヒーローにCTAを置く案を再検討する。効果は未計測。

### ヒーローは写真を主役にする（2026-10-23）
- **決定**: PCは、文字を左（全体の約4割）、写真を右に置き、写真を画面の右端まで広げる。写真は 3:2 の比率のまま見せ、左右の人物を切らない。スマホは、写真を画面幅いっぱいで先に見せ、文字をその下に置く。「※ 写真はイメージです」は写真の右下に重ねる。
- **理由**: ユーザーの指示（「ヒーローの写真を前面に押し出す」）。学生と社会人が同じテーブルで話す場面が、サービス（交流会・取材）をいちばん直接的に伝えるため。
- **検討した案**: 写真を縦長に切り抜いて画面の高さいっぱいに置く案は、左の学生が画面から切れたため採用しなかった。
- **留保**: 実写に差し替えるとき、写真の構図によっては切り抜き位置（CSS の `object-position`）の調整が必要。

### 料金は月払い／年払いの2つを並べる（2026-10-23）
- **決定**: 契約は年間。支払いは月払い（月額40,000円）と年払い（年額400,000円）を同じ大きさのカードで並べる。ヒーローは「月額 40,000円（税込）・年間契約」を主にし、「年払いなら 400,000円（税込）」を小さく添える。年払いのカードには「月払いの合計より 80,000円少なくなります」と、計算で出る差額だけを書く。
- **理由**: ユーザーの指示。年額の金額を主役にすると、ヒーローの「月額4万円」という入口の分かりやすさが下がるため、ヒーローは月額を主にした。
- **留保**: 年払いの金額が税込か、支払い時期（前払いか）は未確認。

### ヒーロー（FV）から料金を外す（2026-10-23）
- **決定**: ヒーローの「月額 40,000円（税込）・年間契約」「年払いなら 400,000円」を外し、企業が得られるものを3項目で示す（学生の目線で、自社の魅力を記事に／記事をWebとInstagramで発信／月1回の交流会で、学生と直接話せる）。料金は #6 料金でだけ見せる。
- **理由**: ユーザーの指示（「より価値の訴求に振る」）。最初に金額を見せると、価値を知る前に費用で判断されやすいため、まず価値を伝える。
- **留保**: ヘッダーのナビに「料金」があるので、金額を先に知りたい人はすぐ移動できる（スマホのヘッダーにはナビがない）。効果は未計測。

### 文面の確認事項（2026-10-23。ユーザー指定の文面のうち、確認が必要なもの）
- **「月1回のレポート」（ヒーロー）と「年1回の年間活動レポート」（サービス内容・料金）が食い違っている**。どちらが正しいか確認する。
- **「長野県最大級の学生向けメディア」**: 「最大級」は比較の表現で、根拠（PV・フォロワー数など、他の学生メディアとの比較）がないと、景品表示法上の問題になるおそれがある（lp-spec.md §6「根拠のない効果の断定」にも近い）。根拠を確認するか、表現を変える。
- **株式会社OMOMOは「運営」か「後援」か**: 紹介文と §1 で異なる。契約の相手（#8 会社情報）との関係も含めて確認する。
- 指定の文面から変えたのは次の表記ゆれだけ: 「メディアメディア」→「メディア」、「webメディア」→「Webメディア」、「月一回」→「月1回」（ページ内の表記に合わせた）、読点の追加。

### サービス内容は、項目を選ぶと画像と説明が出る形に（2026-10-23）
- **決定**: PCは左に6つの項目ボタン、右に画像と説明のパネル。項目に**カーソルを合わせる**と切り替わる（クリック・キーボードでも切り替わる）。スマホは、項目を**タップ**するとその下に開く（アコーディオン）。最初は項目01を開いておく。
- **理由**: ユーザーの指示。スマホにはカーソルがないため、タップで同じ内容を見られるようにした。JavaScript が動かない環境では、全部の説明を縦に並べて表示する。
- **留保**: 画像は項目01（実際の記事のサムネイル）以外まだない。

### ご利用の流れを、年間スケジュールの図にまとめる（2026-10-23）
- **決定**: 1年（12か月）を軸にした図に、3つの列（記事・発信／オモモ会／企業一覧ページ）を並べる。PCは月を横に、スマホは月を縦に並べる。その下に「記事1本ができるまで」（打ち合わせ→取材・撮影→原稿のご確認→公開・発信）を置き、企業の負担を各ステップに書く。
- **理由**: ユーザーの指示（年間スケジュールの追加と、ご利用の流れの整理）。年2回の記事と、毎月・通年で続くもの（交流会・掲載）が、1年の中でどう重なるかを1枚で見せるため。
- **留保**: 記事・取材の時期は例（3〜4か月目・8〜9か月目など、年2回を均等に置いただけ）。

## 色を変えたいとき

> メモ: 指定の緑 `#4E8A3A` に白文字の組み合わせはコントラスト比が約 4.2:1 で、基準の 4.5:1 に届きません。そのためボタンの地には濃い緑 `#3A6B2A`（約 6.3:1）を使っています。`#4E8A3A` はアイコン・装飾・枠線に使っています。
